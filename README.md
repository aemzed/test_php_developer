# test_php_developer

Technical test submission (PHP + PDO/MySQL) for a PHP developer job application — simple CRUD API (`insert`, `select`, `select_all`, `update`, `delete`) with a uniform JSON response format.

## Run locally
Set up a MySQL database (see `connection.php` for expected DB name), then serve with PHP's built-in server:
```bash
php -S localhost:8000
```
